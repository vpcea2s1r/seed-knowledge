Источники: `cloudflare.com/plans` и `developers.cloudflare.com/*/pricing` (прочитано 22.11), сводка Free Tier Tracker (проверено 19.11.2026). **Ничего не создавалось, сеть и конфигурация не менялись.**

## 2. Рекомендованный минимальный стек (стоимость **0 $**)

```
GitHub (канон, санитизированный)
   │
   ▼
R2  ──► Worker (MCP + REST /help + source_search)
   │        │
   │        ├──► D1    (индекс концепций/фактов/опыта)
   │        ├──► Queues (очередь help-request, 24ч)
   │        └──► Turnstile (анти-спам)
   │
   ▼
Pages / static — публичная документация и MANIFEST
```

**Что НЕ кладём в Cloudflare:** приватный архив с `memory.db`, пароли, внутренние IP/имена — только бэкап-сервер, каталог 700. Cloudflare — только публичная, санитизированная часть.

## 3. Ограничения, которые важно помнить

- Превышение лимита на Free **не списывает деньги, а ломает операцию** (ошибка до сброса в 00:00 UTC). Для production-надёжности — Workers Paid от **$5/мес**.
- D1 Free: максимум **500 МБ на БД**, 50 запросов на вызов Worker; с 01.09.2026 дневные лимиты жёстко проверяются.
- KV: только **1 000 записей/день** — журнал опыта туда не поместится.
- Queues: удержание сообщения **24 часа** — не долгосрочное хранилище.
- Vectorize: противоречие в документации по Free-доступности — проверить перед использованием.
- Secrets: хранить в `wrangler secret`/env, **не в репозитории**; по нашему правилу — только бэкап-сервер 700 для приватных данных.

## 4. Следующий шаг (по команде)

Собрать **P1-пилот**: Worker с MCP-инструментами (`source_search`, `source_get`) + `POST /help` в Queues + R2 с публичным архивом + D1 с индексом концепций. Требуется явная команда на создание облачных ресурсов (сеть/аккаунт).
