## 3. Назначение источников (один хозяин на концепцию)

| Источник | Быть каноном для | НЕ делать |
|---|---|---|
| mcp-memory | уроки/ошибки, краткие факты проекта | не экспортировать `.db` целиком в git/облако |
| Semantica | решения с confidence и causally-linked | не дублировать формулировки уроков |
| agentmemory | сессионная телеметрия/сигналы, team feed | не хранить русский текст уроков как канон |
| docs/ | объяснения «почему», протоколы для человека | не быть единственным источником числа |
| SEED | **переносимый concept index + проверенные факты + опыт** | не хранить секреты и сырые БД |
| graphify | код-граф (AST) | не тащить в portable archive |

## 4. Единый индекс концепций

`prototypes/seed/source/concepts.json` — 12 концепций с полями: `id`, `label`, `aliases`, `canonical` (хозяин), `also_in` (где ещё встречается), `fact` (проверенное ядро), `verified`.

Поиск: `python tools/seed.py --source source concepts <запрос>` — ищет по названию, синонимам, факту и списку источников; печатает **канон и все места вхождения**, чтобы не искать дважды.

## 5. Репликация в другую сеть (без утечки секретов)

1. **Публичный архив** (`dr-pack`): только санитизированный SEED (facts/experience/ideas/projects/concepts). Можно в git/Cloudflare/любую машину.
2. **Приватный архив**: `memory.db` + graph + уроки — **только бэкап-сервер, каталог 700**; не в git, не в облако, не в чат.
3. **Корзины**: NAS (B2), бэкап-сервер (B3), GitHub (B4), холодная копия (B5) — `distribute.py` строит план, копирование — по команде.
4. **Для агента на новой машине:** `bootstrap` → `seed concepts <запрос>` → `search` → knowledgeable startup.
