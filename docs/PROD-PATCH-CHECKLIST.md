# Чек-лист выкатки 5 патчей на прод (2.1.38.11)

**Статус:** подготовлено, **НЕ выполнялось**. Прод — только по явной команде оператора «выкатывай патчи на прод».

## 0. Предусловия (обязательны до начала)

- [ ] Свежая dt прода перед изменением (`[local-path]`), размер и MD5 зафиксированы.
- [ ] Версия конфигурации подтверждена XML-выгрузкой `Configuration.xml` = **2.1.38.11** (не по имени архива).
- [ ] 5 `.cfe` на месте, MD5 совпали с официальными: `EF_ОШ67482`, `67496`, `67498`, `68142`, `69476`.
- [ ] Подпись патча проверена (по ИТС патч для базовой конфигурации подписывается тем же ключом, что и конфигурация). **Проверка ещё не сделана.**
- [ ] Тестовая копия прошла проверки: `extensions check`, `/IBCheckAndRepair`, `/CheckModules -AllExtensions`.
- [ ] Пользователи предупреждены: после установки патчей нужен **перезапуск сеанса** (не завершение сеансов — по ИТС).

## 1. Окно (~30–45 мин)

| Шаг | Действие | Проверка |
|---|---|---|
| 1 | Войти в прод в режиме **1С:Предприятие** под пользователем с ролью «Полные права» | вход успешен |
| 2 | **Администрирование → Обслуживание → Обновление программы → Установленные исправления (патчи)** | форма открыта |
| 3 | «Установить исправление…» → выбрать `.cfe` → «Далее» ×5 | после каждого — сообщение об успехе; при несовместимости форма покажет ошибку |
| 4 | Проверить список «Установленные исправления (патчи)» | видны все 5 |
| 5 | **Перезапустить программу/сеанс** | патчи вступили в силу (по ИТС) |
| 6 | «О программе» | версия **2.1.38.11** |
| 7 | Зафиксировать: время, список, кто ставил, результат | запись в `tools/ORCHESTRATION-LOG.md` |

**Не делать:** не ставить патчи через `/LoadCfg -Extension` или `vrunner cfe load` на прод — это обходит форму БСП (нет регистрации, контроля применимости и автоудаления).

## 2. Откат

- Мягкий: в списке «Установленные исправления (патчи)» выбрать патч → «Удалить исправление» → Да.
- Жёсткий: восстановить прод из свежей dt (только по отдельной команде оператора).

## 3. После выкатки

- [ ] Отметить в KB-1C, TOOLS-GAPS, TRACKER.
- [ ] Напомнить: при установке следующего релиза, включающего эти исправления, патчи **должны удалиться автоматически**; на практике иногда не удаляются и блокируют обновление — проверять список перед каждым обновлением.
- [ ] Сверить, что расширение `НГЛУ` не пострадало.
